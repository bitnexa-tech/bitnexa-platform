# Agency Workflow Hub

A full-stack, production-grade agency & freelance operations platform built with Node.js, Express, and native SQLite.

## Core Capabilities
- **Client Portal**: Post projects (Frontend, Backend, Render Deploy, Custom Domain, Reels, Social Media Promotion) with budget (₹ INR) and deadlines.
- **Worker Desk**: View assigned projects, track progress stages, and submit live preview/repository links.
- **Admin Command Center**: Complete visibility of all clients, task requirements, budgets (₹), worker assignment, status control, and user directory.
- **Email OTP Authentication**: 6-digit OTP verification with local console fallback & Nodemailer HTML templates.
- **Render Ready**: 100% prepared for 1-click cloud deployment on Render.

## Quick Start on Localhost
```bash
npm install
npm run seed
npm start
```
Open [http://localhost:5000](http://localhost:5000) in your browser.

See [DEPLOYMENT_RENDER_GUIDE.md](file:///d:/clint%20server/DEPLOYMENT_RENDER_GUIDE.md) for complete walkthrough and Render deployment instructions.
